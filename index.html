Provision & claim a strip

Write this server's address + your home Wi-Fi into the strip. It reboots and dials in — then it shows up under Control.

📱 Option A: Setup using Termux / Python (Recommended)

Step 1: While connected to your normal Wi-Fi / mobile data, download the provisioner script in Termux:

curl -s "https://volta.your-domain.com/controller.py" -o controller.py

Step 2: Factory reset the strip (hold power button 10s until LED flashes rapidly), then connect your phone's Wi-Fi to the strip AP (TONLY_TAP_…).

Step 3: Run this command in Termux to configure Wi-Fi and automatically link the strip to your account:

python3 controller.py --server-ip YOUR_SERVER_IP --token YOUR_TOKEN --ssid "YOUR_WIFI_NAME" --password "YOUR_WIFI_PASSWORD"

The script will read the strip's MAC, send the Wi-Fi credentials, and automatically claim the strip to your Volta account!

🌐 Option B: Provision directly from Browser (Local LAN host only)

⚠️ Note: This option only works if Volta is hosted locally on a home Raspberry Pi/PC. If Volta is running on a cloud VPS, the VPS cannot reach your local 192.168.1.1 AP network; please use Option A (Termux) instead.

  1. Factory-reset the strip: hold the main button ~10s until the LED blinks fast.
  2. On your phone/laptop, join its TONLY_TAP_… network (password below).
  3. Fill Server IP + home Wi-Fi, press Provision. Then rejoin home Wi-Fi.
